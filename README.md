# MicGainControl

Современное приложение для Windows на базе WinUI 3, которое управляет и при необходимости принудительно удерживает заданную громкость микрофона.

## Возможности

- Современный пользовательский интерфейс WinUI 3 (C++/WinRT + Windows App SDK + XAML)
- Автоматическая поддержка светлой и тёмной тем оформления Windows
- Регулировка громкости микрофона ползунком без необходимости нажимать «Сохранить»
- Мгновенное применение настроек
- Работа в системном трее с контекстным меню («Включено», «Открыть окно», «Выход»)
- Автозапуск (через реестр Windows)
- Минимальное потребление системных ресурсов

## Требования

- Windows 10 версии 1809 (10.0.17763) или новее.
- Windows App SDK Runtime 1.5 — приложение неупакованное, поэтому среда выполнения ставится отдельно
  (`https://aka.ms/windowsappsdk/1.5/latest/windowsappruntimeinstall-x64.exe`).
  Если её нет, при запуске появится окно с предложением её установить.

## Запуск

1. Распакуйте архив `MicGainControl.zip` в постоянную папку, например:

```txt
C:\Program Files\MicGainControl\
```

Рядом с `MicGainControl.exe` обязательно должен лежать `Microsoft.WindowsAppRuntime.Bootstrap.dll` из архива — без него приложение не запустится.

2. Откройте свойства файла → поставьте галочку `Разблокировать` → `Применить`.

Это нужно, чтобы Windows не показывал предупреждение безопасности при автозапуске.

3. Запустите `MicGainControl.exe`. Приложение стартует свёрнутым — в системном трее появится значок. Окно настроек открывается двойным кликом по значку или пунктом «Открыть окно» в меню по правой кнопке мыши. Для полного выхода используйте пункт «Выход».

## Сборка проекта локально

Понадобятся:
- Visual Studio 2022 с рабочими нагрузками «Разработка классических приложений на C++» и «Разработка приложений для универсальной платформы Windows». Компонент «Средства C++ (v143) для универсальной платформы Windows» обязателен: без него не запускается компилятор XAML-разметки.
- NuGet CLI (`nuget.exe`) и MSBuild.

### Шаги для сборки

1. Восстановите NuGet пакеты:
```cmd
nuget restore packages.config -OutputDirectory packages
```

2. Соберите решение:
```cmd
msbuild MicGainControl.sln /p:Configuration=Release /p:Platform=x64
```

Готовые файлы будут в `x64\Release\` — `MicGainControl.exe` и `Microsoft.WindowsAppRuntime.Bootstrap.dll`.

## Автозапуск

Программа автоматически прописывает себя в автозагрузку при каждом запуске через реестр Windows по пути:
`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` (параметр `MicGainControl`).

Если вы переместите `.exe` файл в другое место и запустите его, путь в автозагрузке обновится автоматически.

### Как удалить из автозагрузки

Если вы решили удалить программу:
1. Закройте её через контекстное меню в трее.
2. Удалите файлы программы.
3. Чтобы полностью очистить систему, удалите запись `MicGainControl` в `regedit` по указанному выше пути или отключите её во вкладке «Автозагрузка» Диспетчера задач.

## Конфиг

Файл настроек `.MicGainControl.json` создается автоматически в домашней папке пользователя:
`%USERPROFILE%\.MicGainControl.json`.

```json
{
  "enabled": true,
  "microphoneVolume": 100
}
```
